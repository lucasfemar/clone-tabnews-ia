# AGENTS.md

## Sobre o projeto

**clone-tabnews-ia** é uma implementação do [TabNews](https://tabnews.com.br) para o [curso.dev](https://curso.dev), construída com o auxílio de agentes de IA.

## Stack

- Next.js (App Router)
- React
- JavaScript puro (sem TypeScript)

## Estrutura

- `app/`: código da aplicação, seguindo as convenções do App Router do Next.js

## Comandos

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm run start`: servir o build de produção
